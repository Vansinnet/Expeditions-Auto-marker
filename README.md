# Expeditions Auto-marker

A Darktide Mod Framework mod that automatically marks the nearest unfinished Expedition opportunity and can continue with a vault, exit, or extraction target.

## Installation

Install DMF, place the `Expeditions Auto-marker` folder in Darktide's mods directory, and add `Expeditions Auto-marker` to `mod_load_order.txt`.

## Download

Download `Expeditions Auto-marker.zip` from the [latest GitHub release](../../releases/latest). Do not use GitHub's source-code archives for installation.
